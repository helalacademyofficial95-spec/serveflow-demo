# ServeFlow demo website

A responsive, dependency-free landing page for a fictional software company that helps food providers and retail stores coordinate orders, inventory, and team operations.

## Requirements

- A modern web browser (Chrome, Edge, Firefox, or similar)
- Optional: Python 3, for the local server command below

## Preview locally

### Simplest option

Open `index.html` in a web browser.

### Recommended option: local web server

From the project folder, run:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser. Stop the server with `Ctrl+C`.

If `python` opens the Microsoft Store instead of running Python, install Python 3 from [python.org](https://www.python.org/downloads/) or preview `index.html` directly.

## Project files

- `index.html` — page content and semantic structure
- `styles.css` — responsive layout, colors, and component styling
- `script.js` — mobile navigation and footer year

## Notes

The site uses no npm packages, API keys, accounts, paid services, or build steps. The client names and dashboard figures are illustrative demo content; no customer claims, testimonials, contact details, or company performance statistics are presented.
